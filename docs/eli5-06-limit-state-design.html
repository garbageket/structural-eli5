06 · RCC design

Limit state design: factors and combinations

We do not design for the loads we expect. We design for loads pushed up by factors, against strengths pushed down. The gap is the safety.

Load combinations: which one governs?

A member sees many load combinations. Pick lateral load type, set the loads, and see which combination is the worst.

Why the factors exist: scatter

Real loads and real strengths both vary. The factors keep the overlap of the two bell curves very small. Change the scatter and see the chance of failure.

Design strengths: what the code takes away

The code cuts material strength before you use it. This is the other half of safety.
