# Structural engineering in pictures

30 one-page interactive explainers (big drawings, few words, sliders, a short quiz) on structural and geotechnical engineering, with Indian codes. Works in light and dark mode. Each page is one self-contained HTML file, so no build step is needed to view them.

- `docs/` and `site/`: the finished pages (identical copies). Open `index.html`.
- `source/`: Python generators. Run `source/make.sh` to rebuild `site/` (everything except page 20).

Page 20 (retaining walls) is a hand-built file.

## View online with GitHub Pages
Repo Settings > Pages > Deploy from a branch > Branch main, folder /docs. Pages are then served at https://USERNAME.github.io/REPO/

For learning and quick sense-checks only. Design from the project design basis, the geotechnical report and the governing codes.
